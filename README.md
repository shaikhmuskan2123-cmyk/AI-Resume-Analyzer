# 🤖 AI Resume Analyzer & ATS System

An AI-powered Resume Analyzer built using **Python**, **Streamlit**, **spaCy**, and **Scikit-learn**. This application analyzes resumes against a job description, calculates ATS scores, ranks candidates, extracts important information, and provides recruiter-friendly insights through an interactive dashboard.

---

## 📌 Features

- 📄 Upload PDF and DOCX resumes
- 📋 Upload Job Description
- 🎯 ATS Score Calculation
- 🧠 Semantic Similarity Matching
- 🛠️ Skill Extraction
- ❌ Missing Skills Detection
- 👤 Candidate Information Extraction
- 💼 Experience Analysis
- 🎓 Education Extraction
- 🏆 Resume Ranking
- 📊 Interactive Charts
- 📈 Candidate Comparison Dashboard
- 📥 Export Results to CSV
- 🔍 Search and Filter Candidates

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/shaikhmuskan2123-cmyk/AI-Resume-Analyzer.git
```

Open the project

```bash
cd AI-Resume-Analyzer
```

Install dependencies

```bash
pip install -r requirements.txt
```

Download the spaCy model

```bash
python -m spacy download en_core_web_sm
```

Run the application

```bash
streamlit run app.py
```
